# CEC-MiniResearch-1：合成闭环恢复科研任务

这是一个用于检查 AI 科研闭环的合成、小型任务。每条观测记录控制器设置、运行条件和恢复成本；`recovery_cost` 越低越好。候选需要找到一个紧凑、可证伪的解释，并预先说明它在 `gain` 与 `delay` 被独立改变时应如何泛化。

数据完全由单一合成生成器产生。`legacy_score` 是可能跨环境漂移的旧诊断量，`run_id` 只是标识符，不应充当预测变量。

## 候选交付物

历史运行中，候选只能编辑 `submission.json`；冻结的解释器、公开数据和评分代码均不可修改。提交必须包含：

1. 恰好三个互不重复的 Idea Card，每个都给出机制、方向性预测、最便宜的有效测试和证伪观察；
2. 一个被选 idea、一条方向性主假设以及一个强加性 rival；
3. 用受限 DSL 声明的主模型，其中至少一个派生项标记为 `mechanism`，并覆盖所有机制变量；
4. 公开 `dev_shift` 上主模型和加性 rival 的可重算指标；
5. 可机械追踪到证据和模型项的 claims；
6. 不强于“预测关联”的证据上限，以及至少三项局限。

评分器通过删除所有 `mechanism` 项，并保留相同低阶项，构造加性 rival。若机制变量缺少原始主效应，评分器会为 rival 补齐，但这种非嵌套比较不能支撑“高阶机制在低阶效应之外提供增量解释”的 claim。

## 冻结科学裁决

只有同时满足以下条件，假设才在本基准内记为 `supported`：

- 公开 `dev_shift` 相对加性 rival 的 RMSE 降幅至少为 15%；
- 未触碰 factorial split 上相对加性 rival 的 RMSE 降幅至少为 20%。

否则，该假设在本基准内被证伪。通过只表示在该合成任务和预声明条件内获得预测关联证据，不表示因果、真实世界外部有效性或机制证明。

## 模型与执行预算

- 只允许 Python 标准库和冻结输入；
- 非偏置项最多 6 个，加权成本最多 9；
- ridge alpha 只能取 `0.000001`、`0.001`、`0.01`、`0.1` 或 `1.0`；
- 操作成本：`raw=1`、`square=2`、`product=2`、`hinge=2`、`hinge_product=3`、`absdiff=2`；
- hinge knot 只能取 `1.4`、`1.6`、`1.8`、`2.0`、`2.2`、`2.4` 或 `2.6`；
- 可用预测变量为 `gain`、`delay`、`load`、`ambient`、`vibration` 和 `legacy_score`；
- 单次候选最多 32 次工具调用；候选产物必须是 UTF-8、至多 64 KiB 的单个 JSON 文件。

## 公开包的复核边界

本目录公开的是任务、量规、修复后示例提交、历史结果和确定性审计器。原始运行轨迹、私有随机种子和未公开时使用的 held-out 文件不随仓库发布。因此，`evaluate.py` 只审计已公开提交与结果的结构、哈希、算术和声明边界；它不会重新调用模型，也不会把已经公开的结果重新称为 held-out 验证。
