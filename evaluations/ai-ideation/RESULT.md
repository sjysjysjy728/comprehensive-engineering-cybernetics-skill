# AI idea 渐进披露结构回归结果

当前版本通过全部 9 项确定性门禁。纯 idea 请求的静态指令路径由旧版的 `SKILL.md + ai-research.md` 拆为 `SKILL.md + ai-ideation.md`，同时保留问题重构、机制去重、差异预测、反平庸、有限资源结构假设和实现交接字段。

| 口径 | UTF-8 字节 |
|---|---:|
| 公开基线纯 AI 路径 | 25,062 |
| 当前纯 idea 路径 | 17,326 |
| 减少 | 7,736（30.867449%） |
| 当前完整科研路径 | 24,053 |
| 同一上下文先 idea、再完整科研的累计路径 | 30,080（相对旧路径 +20.022345%） |

这些数值是发布文件的静态字节数，不是一次 Agent 运行的 input token。纯 idea 请求更短，但同一上下文若依次保留两个参考文件，累计载荷反而更大。结果支持“渐进披露结构已经实现”和“声明的纯 idea 静态路径减少至少 30%”，但**不支持**以下结论：

- 新版本已经产生更好的 idea；
- 实际 input/cached/output token、费用或墙钟时间已经下降；
- 该拆分在真实科研任务上优于旧版或无 Skill 条件。

旧 AI A/B 的负结果仍然有效且单独保留。下一步需要用未公开任务、匹配条件和独立盲评比较无 Skill、旧版和当前快速路径。

在仓库根目录运行：

```bash
python -X utf8 -I -B evaluations/ai-ideation/evaluate.py --check evaluations/ai-ideation/result.json
```

公开后，本任务只用于检测路由、字段或载荷回归。
