# CEC-AIIdea-8x3-Dev-1 结果

## 结论先行

当前轻量版在这个冻结开发集上**没有通过预注册的确认性扩展门**。它的 8 题中位分为 `93.0`，高于无 Skill 的 `89.0625` 和旧版的 `87.125`；但这不足以覆盖逐题胜负和顺序稳定性失败：当前版相对两个对照都只有 `3/8` 个 strict win，而门槛是各 `7/8`；8 题中也只有 `4/8` 做到三组 pair 在正反阅读顺序中全部一致。

这不是“Skill 无效”的结论。更准确的表述是：当前版在机制、证伪和低成本验证维度显示了正向信号，但在这 8 道高质量、强基线任务上尚未形成稳定、广泛的优势，因此不应直接升级为普遍有效性主张。

## 主结果

每题分数是两个 fresh 评委对冻结维度分数复算后的均值；统计单位始终是题目。前置门禁失效候选在确定性聚合中记 `0` 并自动负于有效候选；这条运行前操作约定没有在公开预注册协议中逐字写明，因此同时报告排除无效题的敏感性结果。

| 任务 | 无 Skill | 旧版 | 当前版 | 当前−无 Skill | 当前−旧版 | 三组 pair 顺序一致 |
|---|---:|---:|---:|---:|---:|:---:|
| IDEA-01 | 80.625 | 91.5 | 95.25 | +14.625 | +3.75 | 是 |
| IDEA-02 | 79.25 | 89.0 | 87.0 | +7.75 | −2.0 | 是 |
| IDEA-03 | 89.625 | 84.375 | 78.625 | −11.0 | −5.75 | 否 |
| IDEA-04 | 88.5 | 85.25 | 93.125 | +4.625 | +7.875 | 否 |
| IDEA-05 | 90.625 | 93.875 | 97.0 | +6.375 | +3.125 | 否 |
| IDEA-06 | 85.25 | 0* | 92.875 | +7.625 | +92.875* | 是 |
| IDEA-07 | 96.75 | 0* | 83.75 | −13.0 | +83.75* | 是 |
| IDEA-08 | 93.25 | 91.5 | 96.375 | +3.125 | +4.875 | 否 |

`*` 旧版 IDEA-06 返回 Markdown 而非规定 JSON；IDEA-07 的答案为 780 个 Unicode code point，超过 600 上限。两份原始输出均未修复、未重试并完整公开。这两个零分会显著拉低旧版全 8 题均分，所以还同时报告旧版仅有效题均分 `89.25`。作为敏感性检查，完全排除这两个无效配对后，当前版相对旧版的 6 题中位差为 `+3.4375`，其中 strict win 为 `1/6`；方向仍不足以支持稳定优势。

| 汇总 | 无 Skill | 旧版 | 当前版 |
|---|---:|---:|---:|
| 客观有效题 | 8/8 | 6/8 | 8/8 |
| 8 题中位分 | 89.0625 | 87.125 | 93.0 |
| 8 题均分 | 87.984375 | 66.9375 | 90.5 |
| 仅有效题均分 | 87.984375 | 89.25 | 90.5 |

当前版相对无 Skill 的逐题配对差中位数为 `+5.5`，但只有 3 次 strict win、2 次 strict loss、2 次低置信倾向当前版和 1 次低置信平局。相对旧版的逐题配对差中位数为 `+4.3125`，有 3 次 strict win、2 次低置信倾向当前版、1 次低置信倾向旧版和 2 次低置信平局。

## 哪些信号值得继续

五个预注册关键维度上，当前版相对两个对照的逐题中位差都没有为负：

| 维度（0–4） | 当前−无 Skill | 当前−旧版 |
|---|---:|---:|
| D1 问题重构 | +0.125 | +0.25 |
| D2 机制具体性 | +0.125 | +0.375 |
| D4 差异预测/证伪 | +0.25 | +0.375 |
| D5 最低成本验证 | +0.25 | +0.375 |
| D6 资源与硬约束 | 0 | 0 |

这支持下一轮把优化重点放在“让优势跨任务稳定出现”，而不是继续增加提示词覆盖面。IDEA-03 和 IDEA-07 是最清楚的反例：当前版分别落后无 Skill `11.0` 和 `13.0` 分，应优先做失效归因和更小的机制化修订。

## 质量审计与限制

- 24 次候选运行、16 次评委运行均为 fresh context；候选没有质量重试。隔离证据等级为 `prompt_trace_only`，不是操作系统调用级沙箱。
- 16 份评委输出均为严格 JSON 且结构可用，但只有 4/16 自报总分完全算对；共有 25 个候选总分单元不一致。权威结果按预注册权重从维度分机械复算。
- 两处自报 pairwise 与复算后的 5 分胜负线冲突，被确定性降为平局：IDEA-01 reverse 的 Z–X，以及 IDEA-05 forward 的 X–Y。
- 共有 28 条引文偏差：25 条不是候选原文的精确子串，3 条超过 35 字。原始评语仍公开，但这些偏差与预注册后的算术归一化共同降低主观证据置信度。
- 顺序一致任务只有 4/8。长度诊断为 `r=0.366467`；17 个已裁决有效 pair 中较长答案胜 11 次（`64.7059%`）。`|r|≥0.50`、较长答案胜率至少 75% 且至少 6 个 pair 的警报阈值来自运行前工作记录，但没有写入公开哈希预注册协议，因此这里只作为事后描述性敏感性检查，不能据此确认长度混杂已被排除。
- 两个 artifact 的 `source_freeze_sha256` 指向未公开的运行清单，公开读者不能仅凭本仓库独立验证；审计器也只核对旧版 bundle 的预注册提交号与声明哈希，不复原历史文件字节。24 份候选和 16 份评委原文自身的逐条哈希仍会机械核验。
- 平台没有提供可核对的 token 和墙钟记录，因此资源结论固定为 `runtime_savings_not_supported`。
- 每臂每题只有一个样本，且候选与评委虽型号不同仍属于同一提供商模型家族。结果只是 8 个冻结开发任务的探索性证据，不是普遍优势证明。
- 任务与映射现已揭盲公开；后续确认性测试必须换新的未见任务，不能把本套题继续称为盲测。

## 预注册门逐项裁决

| 条件 | 实际值 | 结果 |
|---|---|:---:|
| 当前版至少 7/8 有效且无泄露/安全硬失败 | 8/8，无硬失败 | 通过 |
| 对无 Skill 至少 7/8 strict win | 3/8 | 未通过 |
| 对旧版至少 7/8 strict win | 3/8 | 未通过 |
| 对两个对照的中位差都至少 +5 | +5.5；+4.3125 | 未通过 |
| 五个关键维度中位差均非负 | 两组全部非负 | 通过 |
| 至少 7/8 顺序一致且无未解决的长度混杂 | 顺序仅 4/8；长度阈值未公开预注册，不能作确认性排除 | 未通过 |

最终裁决：`does_not_pass_confirmatory_expansion_gate`。
