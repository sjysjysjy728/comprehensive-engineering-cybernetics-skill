# AI idea 快速闭环

只需发现、重构、比较或筛选 AI idea，尚未进入实现、完整实验或论文 claim 时使用本文件。此时只读本文件；候选确定或用户要求实现、复现、正式创新性审计时，再将最小交接包带入 [AI 科研闭环](ai-research.md)。

目标不是一次写出完整研究计划，而是：

```text
在证据、诚信和资源边界内，
以尽量小的上下文和试验成本产生机制上不同的候选，
并找到最能区分候选与竞争解释的下一观测。
```

idea 是待检验假设，不是结论。材料足够时不调用工具；未检索标 `not-searched`，不暗示“首次”。未经授权不外发未公开 idea、私有数据或代码。

## 1. 先重构问题，而不是先换模型

从观察、残差、失败切片、约束冲突或 Pareto 缺口出发；只有目标而无观测时标为假设。仅当当前表述限制动作空间时，形成非同义问题表述，并改变系统边界、受控目标、状态/观测、干预动作、时间尺度或资源约束中的关键项。只有产生不同的可检验预测或行动才保留，措辞变化不算新问题。

优先寻找可观测性、可控性、辨识、时滞/噪声、稳定性、耦合、多目标、适应性或容错方面的结构缺口。它们是启发器，不是必须逐项填满的清单。

## 2. 先生成机制种子，再展开卡片

每个种子先压缩为：

```text
观察/缺口 → 状态表示 → 算子或干预 → 预期差异特征 → 核心成本
```

可从表示与状态、记忆与更新、主动测量、目标与约束、路由与拓扑、反馈与自适应、纠错与资源分工等家族发散；不强求每个家族都有候选。用 `状态—算子—干预—失效特征` 作为机制指纹聚类：名字不同但指纹相同是重复，名字相同但干预响应不同才可能是独立候选。

跨领域类比只有在能对应状态、动作、反馈、扰动、约束和失效条件，并导出目标领域的新预测及类比失效边界时才保留；表面相似不算机制。

候选应预测至少一种能与强竞争解释区分的特征，例如符号反转、阈值、滞回、尺度律、不变量、错误相关结构或特定干预响应。`PRED` 写 HYP 相对 Rival 成立时应出现的差异；`FALSIFIER` 写哪种有效观测会迫使 HYP 或 Core 被拒绝或实质缩窄。若当前观测无法区分，优先提出新的测量；不要用平均分略高代替机制差异。

## 3. 做反平庸检查和有限创新性审计

默认先独立发散；只有缺失领域边界会改变问题时才做最小预检索，系统近邻检索只投入入围候选。写出 `候选 − 最近强方法` 的实质增量，并追问：

- 换一个名称后，机制是否仍与近邻相同？
- 移除 Core 后，预期差异是否仍存在？
- 同预算的常规方法能否解释全部收益？
- 单纯扩模、加数据、加算力或调参能否得到同一结果？

未通过时，把它诚实归类为工程改进、组合应用或复现候选，而不是新机制。检索状态只使用 `not-searched`、`incomplete-search`、`not-located-within-boundary`、`near-neighbor-found` 或 `overlap-found`；搜索边界内未定位到先例不等于证明不存在先例。

## 4. 把普通资源的短板变成结构变量

当候选依赖现有小模型、有限数据、普通设备、检索器或工具时，不以资源名气评分。先问每项资源在哪个窄角色可靠、如何失败、错误是否同源以及能否检测和切换；再考虑便宜前级筛选、异源证据、路由、校验、隔离或稀疏升级。

只有组合机制对匹配预算下的系统增益给出可检验预测时，资源组织本身才是研究 Core。“多调用几个模型”、同源多数票或隐藏使用更强后备不构成该机制。若单体已经满足目标，保留单体；候选入围且需要正式证明结构增益时再读 [资源综合与结构增益](resource-synthesis.md)。

## 5. 分层筛选，避免最容易的候选垄断

先剔除不可证伪、无可用观测、Core 在边界内不可实现、风险不可接受或无法与竞争解释区分的候选。对其余候选展示机制距离、潜在影响、可判别性、可行性、资源、稳健性和阴性价值的 Pareto 权衡，不用不透明总分自动选冠军。

如果证据允许，同时保留一个低风险诊断方向和一个高潜力机制方向；这不是固定配额。只为入围项展开完整 Idea Card，并把“最便宜测试”理解为保留 Core 的最低成本判别动作，而不是最少代码。

## 6. 渐进输出与保真交接

按当前请求停在最浅的充分层级：

1. **Sketch**：给出紧凑的机制种子及指纹，扩大组合只在仍存在重要机制家族或未覆盖不确定性时进行；
2. **Screen**：仅为入围候选补充最近工作差异、Rival、差异预测、Falsifier、Core、最低成本忠实测试和主要风险；
3. **Handoff**：选择候选或开始实现前，冻结以下最小包：

```text
IDEA_ID, OBS_OR_GAP, Q, HYP, RIVAL, PRED, FALSIFIER,
CORE, BOUNDARY, CHEAPEST_TEST, EVIDENCE_STATE, NOVELTY_STATE
```

`EVIDENCE_STATE` 记录观察证据的来源、有效性与适用性；`NOVELTY_STATE` 只记录创新性检索状态，未检索即为 `not-searched`，并附实际检索边界。组合候选的 `CORE` 还要冻结角色、互补来源、共同失效、路由/隔离、协调成本和隐藏升级边界。进入 [AI 科研闭环](ai-research.md) 后，代码、实验和 claim 必须引用这些稳定字段；若 Core 需要改变，显式回到候选选择或缩窄声明，不能静默替换。

当继续检索或展开不再改变候选集合、最强 Rival 或下一判别测试时，以 `saturation` 停止；触及预算、隐私或安全边界时停止并报告未知。不能可靠选出候选时，输出最小缺失观测，不用更长的研究计划掩盖不可辨识性。
